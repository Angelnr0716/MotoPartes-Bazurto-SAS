Entregable 1 Análisis de Problemas

a) Campos que violan la Primera Forma Normal (1FN)

Los campos COD_REPUESTOS, NOMBRES_REPUESTOS, CANT_REPUESTOS y PRECIOS_UNIT violan la 1FN porque contienen varios valores dentro de una misma celda separados por comas. La Primera Forma Normal exige que cada atributo tenga un único valor atómico.

ID_VENTA COD_REPUESTOS
V-001 RP-001, RP-002

En una base de datos relacional cada fila debe contener un solo valor por columna.

b) Dependencias parciales

Al aplicar 1FN, la clave primaria será: (ID_VENTA, COD_REPUESTO)

Existen dependencias parciales porque algunos atributos dependen únicamente de una parte de la clave compuesta.

Dependen de ID_VENTA:

  • FECHA
  • CEDULA_CLIENTE
  • COD_EMPLEADO

Dependen de CEDULA_CLIENTE:

  • NOMBRE_CLIENTE
  • BARRIO_CLIENTE
  • CIUDAD_CLIENTE

Dependen de COD_EMPLEADO:

  • NOMBRE_EMPLEADO
  • CARGO_EMPLEADO
  • SALARIO_EMPLEADO

Dependen de COD_REPUESTO:

  • NOMBRE_REPUESTO
  • PRECIO_UNITARIO

c) Dependencia transitiva

COD_EMPLEADO → CARGO_EMPLEADO → SALARIO_EMPLEADO

El salario depende del cargo y no directamente del código del empleado.

d) Anomalía de actualización

Si cambia el salario de los Asesores Comerciales de $1.500.000 a $1.700.000, habría que modificar todas las filas donde aparezcan esos empleados. Si alguna fila no se actualiza, existirán datos inconsistentes.

Entregable 3 Segunda Forma Normal (2FN)

a) Dependencias parciales encontradas

Tomando como clave primaria compuesta (ID_VENTA, COD_REPUESTO), se identifican las siguientes dependencias parciales:

Entregable 5 Script SQL PostgreSQL

-- Tabla de clientes
CREATE TABLE clientes (
    cedula_cliente VARCHAR(20) PRIMARY KEY,
    nombre_cliente VARCHAR(100) NOT NULL,
    barrio_cliente VARCHAR(50) NOT NULL,
    ciudad_cliente VARCHAR(50) NOT NULL
);

-- Tabla de cargos
CREATE TABLE cargos (
    cod_cargo VARCHAR(5) PRIMARY KEY,
    nombre_cargo VARCHAR(50) NOT NULL,
    salario NUMERIC(10,2) NOT NULL CHECK (salario > 0)
);

-- Tabla de empleados
CREATE TABLE empleados (
    cod_empleado VARCHAR(10) PRIMARY KEY,
    nombre_empleado VARCHAR(100) NOT NULL,
    cod_cargo VARCHAR(5) NOT NULL,
    FOREIGN KEY (cod_cargo)
        REFERENCES cargos(cod_cargo)
        ON DELETE RESTRICT
);

-- Tabla de repuestos
CREATE TABLE repuestos (
    cod_repuesto VARCHAR(10) PRIMARY KEY,
    nombre_repuesto VARCHAR(100) NOT NULL,
    categoria VARCHAR(50) NOT NULL,
    precio_unitario NUMERIC(10,2) NOT NULL CHECK(precio_unitario > 0)
);

-- Tabla de ventas
CREATE TABLE ventas (
    id_venta VARCHAR(10) PRIMARY KEY,
    fecha DATE NOT NULL,
    cedula_cliente VARCHAR(20) NOT NULL,
    cod_empleado VARCHAR(10) NOT NULL,
    FOREIGN KEY (cedula_cliente)
        REFERENCES clientes(cedula_cliente)
        ON DELETE RESTRICT,
    FOREIGN KEY (cod_empleado)
        REFERENCES empleados(cod_empleado)
        ON DELETE RESTRICT
);

-- Tabla detalle venta
CREATE TABLE detalle_venta (
    id_venta VARCHAR(10),
    cod_repuesto VARCHAR(10),
    cantidad INTEGER NOT NULL CHECK(cantidad > 0),
    PRIMARY KEY(id_venta, cod_repuesto),
    FOREIGN KEY(id_venta)
        REFERENCES ventas(id_venta)
        ON DELETE CASCADE,
    FOREIGN KEY(cod_repuesto)
        REFERENCES repuestos(cod_repuesto)
        ON DELETE RESTRICT
);
